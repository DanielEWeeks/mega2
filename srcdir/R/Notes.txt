Let me try a "quick" explanation of how to create/run R for mega2.

  First, you need a mega2 sqlite3 database, call it DB.db

  Second, you need to start R and source
        srcdir/R/mega2.R
        srcdir/R/mega2gene.R
        srcdir/R/pedgene.R

                In principle, you would go about creating a "pedgene.R" analog for
                what other R/bioconductor function you wanted to use.

  Third, run things in R
         init_pedgene("DB.db")

                The important thing in this function is the first line, dbmega2_import(db).
                The rest of the function deals with the fact that we only use the samples
                 where the case/control is 1/2.  So we need to prune.
                We also grab the reference genes from refGene to be compatible with the old
                 program's data

          run()

                We first initialize.  But the important line is
                     applyFnToRanges(DOpedgene, refGene[gs,], indices=3:5)
                refGene is a dataframe of genes, with chromosome, start, end  positions
                the vector after is a three tuple with the index of chromosome, start and
                 end position in the previous data frame.
                And finally, the first argument of "applyFnToRanges" is a function of three
                 arguments that computes for each genotype set selected.
                  The first arg is a matrix of samples x markers containing the genotypes.
                  The second arg is a data.frame of the position information, viz. variables:
                     index, index2, marker, chromosome, position
                  The third argument is a line from the refGene that the data corresponds to.
           NOTE:
		applyFnToGenes() is similar to the above but has more convenient arguments (?).
                Look at the function signature.

           NOTE: refGene is a global data.frame that contains 5 variables: ANYTHING, SYMBOL, TXCHROM,
                  TXSTART, TXEND.  They are unused, gene name, chromosome number, start of transcript
                  range, end of range.  The explicit latter 5 values are the column headers for refGene.
                  Obviously, applyFnToGenes does not need refGene to be defined.
